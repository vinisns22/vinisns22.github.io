_Last updated: October 27, 2026_

This site is a static website hosted on GitHub Pages. We do not run accounts, comments, contact forms or newsletters, and we do not collect personal information.

**Hosting.** GitHub, Inc. hosts this site and may log technical data such as IP addresses for security and operations. See the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

**Analytics.** We use Cloudflare Web Analytics to count page views and see which pages are read and where visits come from. It does not use cookies, does not store anything on your device, does not fingerprint you and does not collect personal information; the counts are aggregated and cannot identify you. See the [Cloudflare Privacy Policy](https://www.cloudflare.com/privacypolicy/).

**Links and images.** Articles link to other websites. Photos come from Pexels and Pixabay, and each one credits its author with a link to the author's profile and the original photo; images marked "AI-generated image" were created with an image generator. Those sites have their own privacy policies.

**Pinterest.** Links from Pinterest carry campaign parameters (such as `utm_source=pinterest`) that only identify the source of the visit, not the visitor.

**Changes.** If we add advertising, affiliate links or any tool that uses cookies, this page will be updated before that happens, describing the cookies used and how to opt out.
